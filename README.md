# PatchGuard External Test Repository

A tiny, intentionally vulnerable Python project for testing PatchGuard on a separate repository.

## Contents
- `app.py`: SQLite demo with an intentionally vulnerable SQL query.
- `requirements.txt`: no third-party dependencies required.
- `TEST_PLAN.md`: safe testing steps.

## Important
This repository is for local security testing only. Do not deploy it or use real data.
Keep your original PatchGuard repository and `.env` untouched.
